## 🚀 SZR School System v1.1.1

SZR School System es una aplicación de escritorio para Windows, desarrollada con Flutter, orientada a la gestión escolar y al control de asistencias.

## ✨ Características técnicas

- Aplicación de escritorio para Windows.
- Desarrollada con Flutter y Dart.
- Base de datos SQLite.
- Componentes nativos para Windows.
- Instalador ejecutable.
- Distribución mediante GitHub Releases.

## 💻 Requisitos

- Windows 10 o Windows 11.
- Arquitectura compatible con el ejecutable.
- Espacio disponible en disco.

## ⚙️ Instalación

1. Descargar `SZR.SYSTEM.exe`.
2. Ejecutar el archivo descargado.
3. Seguir los pasos del asistente de instalación.
4. Finalizar la instalación.
5. Abrir SZR School System desde el acceso directo.
